In a monorepo where the app has its own copy of `react-native` or `react`, Harness's own packages and the packages its runtime depends on now import `react-native` and `react` from the app, so the bundle no longer carries a second React Native with a registry of its own, or a second React. A native component a test registers with `requireNativeComponent` now renders instead of failing with `View config getter callback ... must be a function`.
