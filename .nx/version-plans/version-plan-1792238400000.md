iOS runs no longer compile the permission helper from scratch. Harness now uses the prebuilt XCTest agent that ships with the Apple platform package, so a run reaches a ready agent in about a second instead of waiting on an Xcode build, and CI no longer needs to cache that build. Harness checks the artifact against your installed Xcode and SDK and falls back to building it locally whenever they differ, so upgrading Xcode costs one rebuild rather than failing. Set `HARNESS_IOS_XCTEST_PREBUILT_ROOT` to point at artifacts packed elsewhere, or `HARNESS_SKIP_XCTEST_PREBUILDS=1` to always build locally. Physical devices are unaffected: their agent still has to be signed with your own certificate, so it is still built locally.
