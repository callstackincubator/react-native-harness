`afterEach` hooks now run from the innermost `describe` block outwards, as in Jest. An `afterEach` inside a `describe` block runs before the hooks of the blocks around it, including the top-level hooks of `setupFilesAfterEnv` files and the automatic cleanup after `render`, so it can still check or clean up what the test left. Hooks in the same block keep the order in which they were declared.
