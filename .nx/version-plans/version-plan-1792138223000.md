Harness runs use less CPU. Jest now builds its file map in a single process instead of starting a pool of worker processes on every cold start or file change, and it no longer indexes Harness's `.harness` cache or iOS and Android build output (`ios/Pods`, `ios/build`, `android/build`, `android/.gradle`, `android/app/build`, `android/app/.cxx`). Jest also finds files without watchman, which is now faster than querying it; Metro still uses watchman.
