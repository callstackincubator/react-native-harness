Harness runs use less CPU and no longer need watchman. Jest now builds its file map in a single process instead of starting a pool of worker processes on every cold start or file change, and both Jest and Metro find files with Node's file system APIs, so CI jobs can skip installing watchman. To use watchman again, set `watchman: true` in your Jest config and `RN_HARNESS_DEBUG_USE_WATCHMAN=1` for Metro.
